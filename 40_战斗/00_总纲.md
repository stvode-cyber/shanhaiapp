# 40 · 战斗 · 模块总纲

> 模块编号：40 ｜ 最后更新：2026-10-17 ｜ 状态：✅ 已实现+已验证（BattleScreen + 阵容羁绊 + 连携 + 天气地形）

## 一、模块目的
实现回合制六宠对战：五行×1.6/被克×0.6、类别环×1.3、等级系数、暴击×1.5、随机 0.9~1.0；自动选高亮克制技；接入阵容羁绊、连携组合技、天气地形偏置、七行平衡自检。对应 GDD 六（战斗）、七（技能·组合技）。

## 二、对应引擎与 UI
| 层 | 文件 | 说明 |
|----|------|------|
| Kotlin 引擎 | `shared/.../logic/BattleEngine.kt` | 伤害公式（floor + coerceAtLeast(1)）、bestCounterSkill |
| Kotlin 引擎 | `shared/.../logic/BattleSession.kt` | 回合管理、MAX_TURNS=100、平局血量比例裁决 |
| Kotlin 引擎 | `shared/.../logic/FormationEngine.kt` | 阵容羁绊（阴阳调和/百妖夜行/三才阵/相生阵/青丘幻月） |
| Kotlin 引擎 | `shared/.../logic/ComboEngine.kt` | 同妖连携组合技 |
| Kotlin 引擎 | `shared/.../logic/WeatherEngine.kt` | 雨/雪/风/晴 + 地形偏向 envMultiplier |
| Kotlin 引擎 | `shared/.../logic/BattleIntegrityEngine.kt` | 七行平衡自检（胜率矩阵 + 四布尔不变量） |
| Compose Screen | `composeApp/.../screens/BattleScreen.kt` | 回合制 UI + BattleEngine.damage() + 五行克制显示 |
