# 10 · 探索与地图 · 模块总纲

> 模块编号：10 ｜ 最后更新：2026-10-17 ｜ 状态：✅ 已实现+已验证（osmdroid + MapScreen + SecretScreen 全接入）

## 一、模块目的
实现「出门探索」与「在家秘境」双模式，把真实地理/时间转化为妖气刷怪与补给。对应 GDD 三（探索双模式）、十六·探索（LBS 灵脉）。

## 二、对应引擎与 UI
| 层 | 文件 | 说明 |
|----|------|------|
| Kotlin 引擎 | `shared/.../logic/LocationEngine.kt` | LBS 加权刷怪、昼夜/节气加权、确定性抽样 |
| Kotlin 引擎 | `shared/.../logic/SecretRealmEngine.kt` | 秘境主题、刷妖、五行偏向 |
| Kotlin 引擎 | `shared/.../logic/MapSdkAdapter.kt` | 地图 SDK 契约（双端一致） |
| Kotlin 引擎 | `shared/.../platform/PlatformBridge.kt` (androidMain) | OsmBootstrap.init() + MapSdk |
| Compose Screen | `composeApp/.../screens/MapScreen.kt` | osmdroid 地图 + SpiritNode + 点击弹窗 |
| Compose Screen | `composeApp/.../screens/SecretScreen.kt` | 四类主题秘境刷妖界面 |
