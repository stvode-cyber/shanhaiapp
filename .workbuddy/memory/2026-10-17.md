### 技术决策记录
- **D21 关键决策**：高德地图 SDK → osmdroid 6.1.20（Apache 2.0），Release APK 70MB→3.5MB，零 KEY 闭环
- **Kotlin 版本链**：1.9.23（K1 编译器，不兼容 Compose）→ 2.0.21（K2 编译器，零兼容问题）
- **AGP 版本链**：8.3.2（不兼容 Kotlin 1.9）→ 8.4.2（兼容 Kotlin 2.0）
- **Compose 架构**：MainActivity Scaffold 包裹 + 底部 5 tab + HubScreen 网格路由
- **verify_all.ps1**：全英文避编码坑，一键串起 node×2 + robocopy + gradlew×3

### 遇到的坑
| 坑 | 解法 |
|----|------|
| Gradle 中文路径+emoji → JNI IllegalArgumentException | robocopy 到 C:\temp\shanhaiapp_build 再跑 |
| Compose BOM 无法解析 | 显式 Maven 坐标 |
| Kotlin 1.9 + Compose 不兼容 | 升 Kotlin 2.0.21 |
| osmdroid User-Agent 合规 | OsmBootstrap.init() 显式设置 |
| PowerShell 5 编码坑 | 脚本全英文 |
| osmdroid 需要 Android View 嵌入 | MapScreen 用 AndroidView(MapView) |
