# 阵容羁绊 FormationEngine（GDD 七·技能系统·队伍组合技）交付说明

## 本次完成（任务 #77–#80）
在 ② LBS / ③ 社交 余下可验证项中，补全 GDD 七明确但此前未实现的「队伍组合技 / 阵容羁绊」系统，全部收敛到 `shared`，Swift 严格镜像，并接入双端战斗 UI 与验证闸门。

## 核心交付
- **`FormationEngine.kt`（新增）**：枚举五条组合技并给全队攻击增伤——
  - 阴阳调和：水≥2 且 火≥2
  - 百妖夜行：同类别≥3
  - 三才阵：类别覆盖≥3 种（近似 GDD「三派混编」，玩家单派系，团战多派可扩展）
  - 相生阵：五行齐全（金木水火土）
  - 青丘幻月：狐族（clan=="fox"）≥3
  - 每条 +12% 全队攻击，**叠加上限 +60%（×1.6）**。
- **`Monster` 增 `clan` 字段**（默认 null，定义数据不入库）；狐妖/妖狐/九尾狐 标 `clan="fox"`。
- **战斗接入**：`BattleEngine.damage` 增 `teamAttackMul`（默认 1.0）、`BattleSession` 增 `playerTeamMul`（仅作用于玩家出招）；`GameState.teamSynergies()/teamAttackMultiplier()`。
- **Swift `Core.swift` 完整镜像**：Monster.clan + 狐族标记、FormationEngine、BattleEngine.damage、BattleSession.playerTeamMul、GameState 两方法。
- **双端 UI**：Android `BattleScreen` 构建 `BattleSession` 传入 `teamAttackMultiplier()` 并新增「阵容羁绊」卡；iOS `BattleView` 同构。
