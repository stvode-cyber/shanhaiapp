## 5. 双端一致性核对清单（key points）

编译双双通过后，按以下点人工/单测核对双端行为一致：

- [ ] 五行相克矩阵：金克木 ×1.6、被克 ×0.6、无克制 ×1.0（7 元素，无互克）—— `Element` / `Core.Element.beatsMap`
- [ ] 类别克制环：妖→精 ×1.3 → 精→怪 ×1/1.3 → 怪→灵兽 → 灵兽→妖，单一 4-循环 —— `MonsterCategory.RING` / `Core.MonsterCategory.ring`
- [ ] 伤害公式：floor(raw) 且 coerceAtLeast(1)；暴击率 clamp[0,1] —— 两端数值应完全一致
- [ ] 收妖入口边界：`catchMonster(id)` 未知 id 返回 success=false（零变更）—— Kotlin `CatchOutcome.success` / Swift `guard`
- [ ] 据点占领白名单：`captureNode(node)` 仅接受 `STRONGHOLD_NODES` —— Kotlin `LocationEngine.STRONGHOLD_NODES` / Swift `strongholdNodes`
- [ ] 装备发放：未知 `equipId` 返回 null 丢弃 —— `grantEquip`
- [ ] 排位积分：`rankPoints` 段内 coerceIn(0, 99)—— 抵御坏档越界
- [ ] 信誉分恢复：`dailyRecover` 双边界 coerceIn(MIN, MAX)
- [ ] 装备上界：坏档 stars/tier/副属性 经 `SaveIntegrityEngine.sanitize` 钳到上界（stars≤5、tier≤maxTier、副属性值≤15、条数≤4）
- [ ] 进化钳制：跨稀有度进化时 `tribulations` 钳到新稀有度上限（防超模）
- [ ] 融合配方产物：`FusionEngine.recipeOutputs ⊆ MonsterPool`（RECIPE_OUT 校验）
