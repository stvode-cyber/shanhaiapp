# 20 · 收妖与 AR · 模块总纲

> 模块编号：20 ｜ 最后更新：2026-10-17 ｜ 状态：✅ 已实现+已验证（AR 为纯可选，不影响核心循环）

## 一、模块目的
实现「纯点按三步收妖」（妖出现→点收妖→光环缩到最小再点入葫芦），并定义 AR 收妖契约（可选、操作一致）；落地道德选择分支（镇压/超度影响属性与剧情）。对应 GDD 四（收妖）、十七（自由度·道德选择）。

## 二、对应引擎与 UI
| 层 | 文件 | 说明 |
|----|------|------|
| Kotlin 引擎 | `shared/.../logic/CaptureEngine.kt` | 收妖概率（辅助满精度 0.98 / 神无辅助 0.06 保底）、环周期公式 |
| Kotlin 引擎 | `shared/.../logic/ARCaptureController.kt` | ARStatus 三态、纯委托 CaptureEngine |
| Kotlin 引擎 | `shared/.../logic/MoralChoiceEngine.kt` | SUPPRESS镇压atk×1.10 / TRANSCEND超度def·hp×1.08 |
| Compose Screen | `composeApp/.../screens/CaptureScreen.kt` | 光环收缩动画 + CaptureEngine.resolve() |
